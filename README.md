# ⚡ DARK-CLI

Современный кроссплатформенный CLI/TUI лаунчер и диспетчер задач в стиле **OpenCode / Claude Code**. Позволяет мгновенно запускать любые программы, скрипты, сервисы и команды через конфигурируемый файл `config.toml`, используя красивый интерфейс терминала или прямой запуск из командной строки.

---

## ✨ Основные возможности

- **Интерактивный TUI в стиле OpenCode**:
  - Верхний статус-бар с индикатором состояния, текущей директорией и быстрыми вкладками `[1..4]`.
  - **Каталог действий (Actions View)**: список программ с категориями (`Dev`, `Git`, `System`, `Web`), хоткеями и подробным описанием.
  - **Консоль вывода (Output View)**: отображение вывода запущенных процессов, времени выполнения (`duration`), кода возврата (`exit code`) со скроллингом.
  - **История (History View)**: хронологический лог всех запусков со статусами `✔ / ✖`.
  - **Командная палитра (Fuzzy Command Palette)**: мгновенный нечеткий поиск по названию, ID, категории или описанию по нажатию `/` (как в OpenCode / VSCode).
  - **Slash-команды**: поддержка ввода команд `/run <id>`, `/reload`, `/clear`, `/help`, `/exit`.
- **Конфигурация через `config.toml`**:
  - Легко добавлять свои скрипты, программы и ярлыки без необходимости перекомпилировать проект.
  - Горячая перезагрузка конфигурации по нажатию `r` прямо в интерфейсе!
- **Headless CLI режим**:
  - Запуск настроенных действий напрямую из терминала или скриптов: `dark-cli run <id>`.
  - Просмотр всех действий в виде консольной таблицы: `dark-cli list`.

## 🚀 Быстрый старт

### Сборка и запуск TUI

```bash
# Запуск интерактивного интерфейса
cargo run

# Или сборка релизной версии
cargo build --release
.\target\release\git_project1.exe
```

### Команды CLI (Headless)

```bash
# Показать красивую таблицу настроенных действий
cargo run -- list

# Запустить конкретное действие по ID (например, git-status или cargo-check)
cargo run -- run git-status
```

## ⌨ Горячие клавиши (Keybindings)

| Клавиша | Действие |
|---|---|
| `Enter` | Выполнить выбранное действие |
| `↑` / `↓` или `j` / `k` | Перемещение по списку или скролл вывода |
| `PageUp` / `PageDown` | Быстрый скролл вывода (на 10 строк) |
| `Tab` / `Shift+Tab` | Переключение между вкладками |
| `1`, `2`, `3`, `4` | Быстрый переход: Actions, Output, History, Help |
| `/` | Открыть всплывающую Command Palette (нечеткий поиск) |
| `:` | Открыть строку ввода slash-команд |
| `r` | Горячая перезагрузка `config.toml` |
| `?` | Открыть справку |
| `q` или `Ctrl+C` | Выход из программы |
| `c`, `b`, `t`, `g`, `e` | Быстрые однобуквенные клавиши, привязанные к действиям |

## ⚙ Конфигурация (`config.toml`)

Файл `config.toml` находится в корне проекта (или в системном каталоге `%APPDATA%/dark-cli/config.toml`).

Пример добавления новой программы или действия:

```toml
[[actions]]
id = "my-script"
name = "My Custom Script"
description = "Запуск моего Python скрипта"
category = "Tools"
command = "python ./scripts/main.py"
shortcut = "m"
# cwd = "C:\\path\\to\\dir"
```
